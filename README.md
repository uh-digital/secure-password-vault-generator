# 🔒 Secure Password Vault Generator

A sleek, premium cyber-vault utility designed to enhance account security. This interface functions both as a live analytical password strength meter and an automated high-entropy secure code generator.

## 🛠️ Key Features
- **Live Reactive Strength Meter:** Evaluates password inputs in real-time using regular expressions, dynamically updating colored progress bars (Weak 🛑 → Medium ⚠️ → Strong 💪).
- **Customizable Entropy Controls:** Toggles to include uppercase letters, numbers, lowercase scripts, and specific cryptographic symbols based on custom lengths (6 to 32 characters).
- **One-Click Clipboard Export:** Instant secure output backup via optimized clipboard interactions, supported by layered layout depths for perfect click alignment.
- **Top-Center State Indicators:** Replaces outdated default alerts with modern, responsive floating toast nodes to confirm copy and generation updates seamlessly.

## 💻 Tech Stack
- **HTML5:** Secure parameter input controls and structural data tables.
- **Tailwind CSS:** Neon gradient highlights, shadow utility masks, responsive card wraps, and reactive state sliders.
- **Vanilla JavaScript:** Regular expression character parsing, dynamic data block evaluation loops, explicit click event handlers, and fluid toast animation timers.
