# 🔐 Safe Vault Generator

A premium, user-friendly, and lightweight password generator built with **HTML5, Tailwind CSS, and Vanilla JavaScript**. This tool allows users to instantly generate highly secure yet completely **human-readable (decrypted form)** passwords without confusing character glitches.

## ⚡ Live Features
- **True Decrypted Form:** Generates clean, memorable, and pronounceable words combined with digits and symbols (No confusing characters like `0`, `O`, `l`, `I` or complex coding symbols).
- **Unlimited Generation:** No restriction on operations. Users can generate unlimited code variants seamlessly.
- **Top-Center Custom Toast Notifications:** Elegant glassmorphic alerts sliding down from the top to notify when a password is generated or safely copied.
- **Interactive Security Strength Meter:** Live dynamic bar changing states (Weak ⚠️, Medium ⚡, Strong 💪) with dynamic color transitions (Red ➔ Yellow ➔ Emerald).
- **Fully Responsive UI:** Dark-themed cyberpunk/vault aesthetic tailored beautifully via Tailwind CSS utilities.

## 🛠️ Tech Stack
- **Structure:** HTML5
- **Styling:** Tailwind CSS (Fluid Layouts & Translucent Glassmorphism)
- **Logic Engine:** Vanilla JavaScript (DOM Manipulation & Custom Phrase Algorithms)

## 🚀 How It Works
1. Select your preferred constraints using the **Settings Panel** Matrix (Uppercase, Lowercase, Numbers, Symbols).
2. Adjust your preferred length (8 to 16 characters) using the sleek fluid **Range Slider**.
3. Click **⚡ Generate Secure Code** to spawn a decrypted user-friendly password.
4. Hit the clipboard icon `📋` to save it instantly with smooth real-time notification feedback.
